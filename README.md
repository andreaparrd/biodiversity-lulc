## BIODIVERSITY IN PRODUCTION LANDSCAPES: ANALYZING SPECIES OCCURRENCES ACROSS LAND USE AND LAND COVER MOSAICS (2023-2025)
*Capstone project for the YSE Environmental Data Science Certificate.*

*Author: Andrea Parra· Last updated: Nov, 2026*

## Research Questions
1. How does species occurrence vary across land use categories (from native forests and savannas to plantations and infrastructure), evaluating whether observations concentrate near conservation areas and identifying up to what distances species disperse from them?
2. How do land use classifications influence each taxonomic class, identifying whether specific species are restricted to a single land use category or occur across multiple categories?
3. Do threatened species spatially cluster within specific corridors established across the landscape, allowing us to identify hotspots and infer the use of established corridors?

## Summary

This project explores how Land use and Land cover (LULC) within a forestry production mosaic influences the spatial occurrence of terrestrial fauna (mammals, birds, reptiles, and amphibians). Using a monitoring dataset generated by field collaborators during routine operational routes, (functioning as a citizen science initiative). This analysis evaluates wildlife distribution across native ecosystems, forestry plantations and infrastructure. 

## Data Sources

1. **Fauna Monitoring Database (2023–2025):**: tabular and spatial point dataset. Key variables include observation date, number of individuals, taxonomic classification, conservation threat categories and spatial coordinates in UTM.
2. **Land Use and Land Cover (LULC):**  vector polygon dataset delineating land management and habitat categories.

## How to run the code
All scripts are Google Colab notebooks written in R. Mount your Google Drive when prompted at the start of each notebook and run them in numerical order:

- `scripts/0_project_setup.ipynb` mounts Google Drive and creates the project directory structure (raw_data/, clean_data/, figures/, and scripts/).

- `scripts/1_data_cleaning.ipynb` reads raw_data/bio_monitoring.csv, executes parsing, standardization, cclenaning and exports clean_data/bio_monitoring_clean.csv.

- `scripts/2_exploratory_analysis.ipynb` (in development).

- `scripts/3_spatial_analysis.ipynb` (planned).

## Data cleaning steps
The preprocessing workflow in scripts/1_data_cleaning.ipynb transforms the raw field export into an analysis-ready dataset through five steps:

1. Delimitation: splits delimited raw records into structured fields and enforces explicit R data types.
2. Standardization: transform observation dates (DD/MM/YYYY) into ISO-8601 format (YYYY-MM-DD) via lubridate.
3. Harmonization: trims extra whitespace and recodes missing or blank conservation fields into explicit NA.
4. Validation: verifies that X and Y coordinates are valid numeric values.
5. Export: writing the final table to clean_data/bio_monitoring_clean.csv.
